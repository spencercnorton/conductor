# Support

- **Something is broken** — [open a bug report](https://github.com/spencercnorton/conductor/issues/new/choose).
- **A question, or an idea** — [Discussions](https://github.com/spencercnorton/conductor/discussions).
- **A security problem** — [private vulnerability reporting](https://github.com/spencercnorton/conductor/security/advisories/new), never a public issue. See [SECURITY.md](SECURITY.md).
- **Documentation** — the README and the `docs/` directory in this repository.

This is one developer's project, maintained in the open; there is no
support contract and no e-mail address. Issues are answered as time allows,
and the newest tagged release is the only one that gets fixes.

If Conductor saves you time, you can [support its development](https://buy.stripe.com/8x26oH2U44f65TRe574wM04).
